# МапаПодійUA — PWA

Цей пакет додає PWA-оболонку навколо існуючого `map.html`.

## Структура GitHub Pages

Поклади файли у репозиторій `MapDoUA` поруч із уже існуючим `map.html`:

```text
MapDoUA/
├── index.html
├── map.html
├── manifest.json
├── sw.js
├── offline.html
└── icons/
    ├── icon-192.png
    ├── icon-512.png
    └── maskable-512.png
```

Відкривати потрібно:

https://eso-net-live.github.io/MapDoUA/

`index.html` відкриває існуючий `./map.html` всередині PWA. Тому твій поточний `map.html` не потрібно переписувати.

## Встановлення на Android

Chrome/сумісний браузер → меню ⋮ → «Додати на головний екран» або «Встановити застосунок».
